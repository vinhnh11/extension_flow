Flow: mở sẵn 1 project và chọn model / tỉ lệ / số lượng trong cài đặt của Flow. BatchPilot chỉ chờ đủ “Kết quả / prompt”.

Hàng đợi

Giữ side panel mở trong lúc chạy.

    Dựng chuỗi node kéo-thả: Ảnh → Prompt → Flow / ChatGPT / Grok → Chờ → Tải về / Telegram. Dùng @slug trong prompt để chèn text hoặc ảnh từ node khác.

    Báo lỗi selector

    Khi Flow / ChatGPT / Grok đổi giao diện: mở đúng chỗ bị lỗi trên trang đó (vd. bấm mở menu cài đặt của Flow), rồi bấm nút dưới. Nội dung được copy sẵn để dán cho dev.
